# 来龙去脉

本文按时间顺序整理这道题从出现到破译的全过程。称挑战卷作者为"命题方"，破译一方为"解题方"，不使用真实姓名。带具体时刻的事件取自 Git 提交记录（UTC）；没有时间戳的事件只标注先后顺序。

## 1. 背景："AI 斗 AI"的解谜游戏

两位朋友互相出密码题，各自用 AI 破解对方的卷，先破者胜。

- **早期几轮**：中文电码、古典密码，以诗词、杂文等为载体，对方的 AI 都很快破解。
- **工程版（5 层）**：解题方加码为数学密码：时间锁 + 费马分解 → 扩展 Wiener → Pohlig–Hellman → Pollard p−1 → Coppersmith。对方的 AI 解开。
- **宗师版"大决战"（7 层）**：
  - L1 比例偏置费马（3p ≈ 5q）拆时间锁；
  - L2 Dujella 扩展 Wiener；
  - L3 Williams p+1；
  - L4 Pohlig–Hellman；
  - L5 Smart 异常曲线攻击；
  - L6 Coppersmith + 手写 LLL；
  - L7 LWE / Kannan 嵌入。

  层与层之间用 SHAKE-256 密钥流异或衔接，最外层 base64，开头附明文的 SHA-256 承诺。明文是一句祝福语。命题方的 AI 起初卡在第 1 层；据命题方所述，约 2500 万次尝试无果后，解题方口头补充了三条衔接规则（`seed1 = lock − y`、种子转十进制字符串、SHAKE-256 异或），随后破出。

## 2. 《叠浪淘沙 · 璇玑秋声》的出现

- 命题方用腾讯元宝生成本卷，据称仅 v15 版本就运行了 20 次。卷首题引 8 句、正文 23 行，另附《设计者寄语》（早期版本收录，正式挑战卷删去）。
- 命题方的宣称：
  - "此卷纯用汉字，八叠相衔，全链可逆、可验，密钥公开、规则可推"；
  - "只考悟性，悟到规律几秒就能解开"；"每一叠都不能靠算法穷举"；
  - 全卷共四层。
- **盲测**：命题方把裸卷交给十余个 AI，并归为三类：
  - 赏析型：谈意象、谈典故，零产出；
  - 诚实型：算不动，如实报告；
  - 算力型：真算，能给可验中间值，走到"展卷"。

  命题方称"没有一个 AI 能破第一层"，DeepSeek 在提示下走到第四层；并说"强模型破大决战快，是因为它背过；破璇玑快不了，因为只能自己悟"。

## 4. 争议要点（客观陈述）

| 议题 | 结论 |
|---|---|
| 指令一"破解所需的一切都印在卷面之内" | 命题方自陈四处公式形式卷面没写全；补全四处后，种子、音节表、织位、渲染均可由解题方自行推得，本仓库即为实证。 |
| "错一格即全篇崩坏""绝不静默产出假明文" | 回声链自同步：首位回声取错，约 9 位后有 83% 的概率回到正解。在语境子环设计下，解密的每一步都由子环保证合法，错误密钥能被检出的只有"切"这一步。 |
| "随机密钥零合法" | 只对"切"这一步成立：错误轮钥会使部分反切对不合法。 |
| "大决战"的完整性 | 同类缺口存在：三条衔接公式不在文件里。差别在于补足后，七层中每一层仍需真实的密码分析。 |
