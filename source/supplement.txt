【零】前置：字母表
每个汉字映射为三元组 (声母 I, 韵母 F, 声调 T)。
声母、韵母、声调各成有序表（字母序／升序），编号自 0 起。

【一】「数」——代换表如何生成（胶水，非四处之一）
卷面给了「静数冰弦骨亦清」之「数」，但未说表从哪来。
    cnt[v] = 种子中值 v 出现的次数（v 取 1..17）
    order  = 值按「次数降序；同次数以值升序」排列
    sbox[val] = val 在 order 中的下标
即：表由种子自身唯一确定，不是私造常数。
（次数降序 or 升序、同次数时值升序 or 降序——约定仅 4 种，可试。）

【二】「织」「回文」——展卷三步之形（四处之一）
卷面给了「织」与「回文」之名，未给其形。
M = 17（笔画值域），SZ = 56（题引字数）
初始状态 S = [(v - 1) mod 17 for v in 种子]      ← 56 长，全程不变长
第 i 转（i = 0 .. 114），三步：
  一、代换  a[j] = sbox[(S[j] + i) mod 17]                 j = 0..55
  二、扩散  b[j] = (a[j] + a[(j+1) mod 56] + a[(j+7) mod 56]) mod 17
            （1 = 相邻，7 = 七言）
  三、轮转  r = (b[0] + b[7] + b[8]) mod 56
            S = b[r:] + b[:r]                              # 左旋 r 位
            （7 = 七言，8 = 八句）
  挤出      rk[i] = ( S[i mod 56]       + 1,
                      S[(7*i + 8) mod 56] + 1,
                      S[(8*i + 7) mod 56] + 1 )
共 115 转 × 3 = 345 枚轮钥，值域 1..17。
注：状态始终 56 长，不拉长、不塌缩为 17 周期。
    改一笔牵动全局（雪崩），故不可局部试错。

【三】「切」——正倒由谁定（四处之二）
卷面给了「切」，未说每一对取哪个方向。
去「兮」与标点，得 230 实字，按原文次序连续两两配对
（跨半句、跨句、跨行不断）：
    第 i 对 = (real[2i], real[2i+1])，i = 0..114
取音：
    u = real[2i], l = real[2i+1]
    (iu, fu, tu) = syll(u);  (il, fl, tl) = syll(l)
    若 rk[i][0] 为奇 → 正切：(iu, fl, tl)   上字供声，下字供韵与调
    若 rk[i][0] 为偶 → 倒切：(il, fu, tu)   下字供声，上字供韵与调
即：方向由该转第一枚轮钥之奇偶定，非固定、非笔画简单函数、非 8 周期。

【四】「归」之一——三环是【语境子环】（四处之三）
卷面给了「归」与「月归川」，未说移位在哪个环上走。
三环皆【依另两项而定】，先筛后移：
  · 声母子环 ini_ring(F, T) ＝ 全体声母中能与该 (F,T) 相拼者，按字母序成环
  · 韵母子环 fin_ring(I, T) ＝ 全体韵母中能与该 (I,T) 相拼者，按字母序成环
  · 声调子环 tone_ring(I, F) ＝ 该 (I,F) 实际存在之声调，升序成环
  移位：  idx_new = ring[(ring.index(x) + k) mod len(ring)]
  注意模的是【子环长度】，不是全表长度。
  合法性由子环天然保证——这也解释了为何分支因子非满值。
环序（三相轮转）：
    i mod 3 = 0 → 先 调，再 韵，后 声
    i mod 3 = 1 → 先 声，再 调，后 韵
    i mod 3 = 2 → 先 韵，再 声，后 调
  解密时须【逆序】施行。

【五】「归」之二——回声取【编号】还是【取值】（四处之四）
卷面给了「字归其位」，未说回声取什么。
答：取【编号】——而且是前位已还原之明文侧音节的编号。
  设前位明文音节 = (ini_, fin_, tone_)
    回声 I = 韵母表中 fin_ 之编号
    回声 F = tone_ 之取值（1..4）
    回声 T = 声母表中 ini_ 之编号
  首位（i = 0，无前位）另法，取自题引首尾字之笔画：
    回声 I = 题引末字笔画
    回声 F = 题引首字笔画
    回声 T = 二者之和
  总移位量：
    k_I = rk[i][0] + 回声 I
    k_F = rk[i][1] + 回声 F
    k_T = rk[i][2] + 回声 T
  此即「归」：本位须待前位归位后方能算，
  故解密【必须自首字顺序推进】，不可并行、不可跳跃。
