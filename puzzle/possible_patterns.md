# 核心规律与装置完整规格（Possible Patterns & Verified Spec）

结合初期统计发现（行内相邻反切对 $z \approx 6.1$）与命题方后续发布的《〈叠浪淘沙 · 璇玑秋声〉四处补遗》，密码装置的完整数学结构已全部锁定并验证通过：

## 1. 字母表（S21 严格声韵调体系）
- **声母表 `INI_ORDER`（22 项，0 起编号）**：
  `['', 'b', 'c', 'ch', 'd', 'f', 'g', 'h', 'j', 'k', 'l', 'm', 'n', 'p', 'q', 'r', 's', 'sh', 't', 'x', 'z', 'zh']`（零声母必须排在最前；排在末尾时解密输出退回随机水平）。
- **韵母表 `FIN_ORDER`（36 项，字母序，0 起编号）**：
  基于 GB2312 6763 常用字的 pypinyin 首读音（不收空韵母与轻声），统一 `ü -> v`；合法带调音节共 1194 个。
- **声调 `T`**：取 `1, 2, 3, 4` 四声升序。

## 2. 「数」：S-Box 由种子自生
- 题引 56 字笔画取值 `v in 1..17`，统计各值在 56 字中出现的次数 `cnt[v]`。
- 按**次数降序、同次数以值升序**排列得到 `order`（长度为 17），`sbox[val]` 为 `val + 1` 在 `order` 中的下标：
  `sbox = [11, 15, 2, 5, 3, 0, 6, 1, 7, 4, 8, 12, 10, 13, 14, 16, 9]`（由卷面题引笔画实算）。

## 3. 「织」：56 长状态机与 115 转轮钥生成
- 初始状态：`S = [(v - 1) mod 17 for v in 种子]`（长度 56）。
- 第 `i` 转（`i = 0..114`）：
  1. **代换**：`a[j] = sbox[(S[j] + i) mod 17]` (`j = 0..55`)
  2. **扩散**：`b[j] = (a[j] + a[(j+1) mod 56] + a[(j+7) mod 56]) mod 17`
  3. **轮转**：`r = (b[0] + b[7] + b[8]) mod 56`，状态左旋 `r` 位 `S = b[r:] + b[:r]`
  4. **挤出轮钥**：
     `rk[i] = (S[i mod 56] + 1, S[(7*i + 8) mod 56] + 1, S[(8*i + 7) mod 56] + 1)`

## 4. 「切」：反切方向由 `rk[i][0]` 奇偶唯一确定
- 去掉“兮”与标点得 230 实字，连续两两配为 115 对 `(u, l) = (real[2i], real[2i+1])`。
- 若 `rk[i][0]` 为**奇** $\rightarrow$ **正切** `(iu, fl, tl)`（上字供声，下字供韵与调）。
- 若 `rk[i][0]` 为**偶** $\rightarrow$ **倒切** `(il, fu, tu)`（下字供声，上字供韵与调）。
- **验证结果**：115 对切出的带调音节 **115/115 全部合法**（34 个单向反切强制对 100% 命中）。

## 5. 「归」：语境子环移位、三相轮转与明文回声链
- **语境子环**：固定另外两维，仅在能相拼成合法音节的子集上按字典序/升序成环（`ini_ring(F,T)`、`fin_ring(I,T)`、`tone_ring(I,F)`），模数为**子环长度**。
- **回声（前位明文反馈）**：
  - `i = 0`：`回声 I = 题引末字“川”笔画(3)`，`回声 F = 题引首字“万”笔画(3)`，`回声 T = 二者之和(6)`。
  - `i > 0`：设前位已还原明文音节为 `(ini_, fin_, tone_)`，则 `回声 I = fin_ 编号`，`回声 F = tone_ 取值(1..4)`，`回声 T = ini_ 编号`。
- **三相轮转（解密逆序施行）**：
  - `i mod 3 == 0`：加密 `调 -> 韵 -> 声` $\Rightarrow$ 解密 `声 -> 韵 -> 调`
  - `i mod 3 == 1`：加密 `声 -> 调 -> 韵` $\Rightarrow$ 解密 `韵 -> 调 -> 声`
  - `i mod 3 == 2`：加密 `韵 -> 声 -> 调` $\Rightarrow$ 解密 `调 -> 声 -> 韵`

## 6. 「织位」（回文）：已确定（Run 8）
- 明文 115 个音节按行写入 23 行 × 5 列的网格（正文 23 行、每行 5 对）。
- 加密顺序沿"回"字形逆时针螺旋读取：从右上角出发，沿最右一列向下到底，再沿末行向左、首列向上、首行向右，逐圈内收。
- 解密：按第 1–5 节解出 115 个音节后，把第 j 个音节回填到螺旋路径的第 j 格，再逐行读出即为明文。
- 证据：在 3875 种网格写读排列中唯一突出（覆盖 77；随机 2000 次最高 62）；读出为通顺的现代汉语短简；重新加密逐位复现密文。实现见 `analysis/solve.py`。
